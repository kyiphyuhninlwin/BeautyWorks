# Beauty Works API

A cosmetics product management RESTful API built with ASP.NET Core Web API and Entity Framework Core.

## Features

- Product management
- Category management
- Product type management
- Subcategory management
- Brand management
- Variant management
- CRUD operations
- Product filtering
- Product sorting
- Pagination
- Image upload and management
- Swagger API documentation

## Tech Stack

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Swagger / OpenAPI

## Project Structure

Category
    ↓
Product Type
    ↓
Subcategory
    ↓
Product

## API Documentation

Swagger is available for testing and exploring the API endpoints.

## Getting Started

1. Clone the repository
2. Configure the database connection
3. Apply migrations
4. Run the application
5. Open Swagger
